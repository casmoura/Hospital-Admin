# Hospital-Admin
Business Information System to manage administration data on a large hospital.

This is a webapp to be run under any platform and browser. It was developed under Ubuntu Linux 24.04

INSTALLATION 

Interactive Map & Data Visualization Dashboard
An interactive Python web application designed for geographic data visualization and analytics, focusing on Rio Grande do Sul. This guide provides step-by-step instructions to set up, run, and deploy the application to the web.

Prerequisites
Ensure you have the following installed on your system:

Python 3.9
Git
pip (Python package manager)

Local Installation & Setup
1. Clone the Repository
Clone this repository to your local machine:

Bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

2. Create and Activate a Virtual Environment
It is recommended to use a virtual environment to manage dependencies:

Linux / macOS:

Bash
python3 -m venv venv
source venv/bin/activate

Windows:

DOS
python -m venv venv
venv\Scripts\activate

3. Install Dependencies
Install all required Python packages:

Bash
pip install -r requirements.txt

Note: If you do not have a requirements.txt file yet, create one containing your app's dependencies:

Plaintext
dash
plotly
pandas
gunicorn
python-dotenv

It is strongly advised to use Anaconda to manage all Python's dependencies.


4. Set Up Environment Variables (Optional)
This app requires API keys (such as Mapbox or CARTO tokens). Create a .env file in the root directory:

Code Snippet 
MAPBOX_ACCESS_TOKEN=your_mapbox_token_here
CARTO_API_KEY=your_carto_key_here
5. Run the Application Locally
Execute the script to start the development server:

Bash
python app.py
Open your browser and navigate to [http://127.0.0.1:8050/](http://127.0.0.1:8050/) (or the port specified in your terminal).

Web Deployment Guide
Option 1: Deploy to Render (Recommended for Production)
Render provides free hosting for Python web applications.

Add gunicorn to requirements.txt:
Ensure gunicorn is listed in your requirements.txt.

Define Server Instance in app.py:
Ensure your app exposes the underlying server (e.g., for Dash):

Python
app = dash.Dash(__name__)
server = app.server  # Required for Gunicorn
Create a Procfile:
Create a file named Procfile (without extension) in the root folder:

Plaintext
web: gunicorn app:server
Deploy via Render Dashboard:

Push your code to GitHub.

Sign in to Render.

Click New + > Web Service.

Connect your GitHub repository.

Set the Start Command to gunicorn app:server.

Add any necessary environment variables under the Environment tab.

Click Create Web Service.

Option 2: Quick Public URL via ngrok (For Testing/Demos)
If you want to make your locally running app accessible on the internet instantly without deploying to a cloud server:

Install ngrok:
Download and install ngrok from ngrok.com.

Start Your App Locally:

Bash
python app.py
Expose the Local Port:
In a separate terminal window, run (adjusting 8050 to your app's port):

Bash
ngrok http 8050
Copy the public URL generated by ngrok ([https://xxxx.ngrok-free.app](https://xxxx.ngrok-free.app)) and share it.

Map Style Troubleshooting
If the base map displays an "API KEY REQUIRED" watermark:

Change the map style in app.py to "open-street-map" for an open-source alternative requiring no credentials.

Alternatively, supply a valid API key for CARTO or Mapbox in your environment configuration.

SETTING UP THE WEBSERVER

Step 1: Keep Streamlit Running Permanently
nohup streamlit run app.py --server.port 8501 --server.address 127.0.0.1 > streamlit.log 2>&1 &

Step 2: Configure Apache as a Reverse Proxy
      2.1 Create a new Apache configuration file:
      sudo nano /etc/apache2/sites-available/streamlit_app.conf
      2.2 Paste the following configuration into the file:
      <VirtualHost *:80>
    ServerName biana-local.hcpa.edu.br

    ProxyPreserveHost On

    # Target the Streamlit WebSocket connection (Crucial for Streamlit to load)
    ProxyPass /_stcore/stream ws://localhost:8501/_stcore/stream
    ProxyPassReverse /_stcore/stream ws://localhost:8501/_stcore/stream

    # Target normal HTTP traffic
    ProxyPass / http://localhost:8501/
    ProxyPassReverse / http://localhost:8501/

    ErrorLog ${APACHE_LOG_DIR}/streamlit_error.log
    CustomLog ${APACHE_LOG_DIR}/streamlit_access.log combined
</VirtualHost>

Step 3: Enable Modules and Restart Apache
    # Enable proxying modules
sudo a2enmod proxy
sudo a2enmod proxy_http
sudo a2enmod proxy_wstunnel

# Enable your new site configuration
sudo a2ensite streamlit_app.conf

# Test that the configuration has no typos
sudo apache2ctl configtest

# If it says "Syntax OK", restart Apache!
sudo systemctl restart apache2
